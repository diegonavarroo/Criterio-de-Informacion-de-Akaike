# Criterio-de-Informaci-n-de-Akaike
El objetivo del script es determinar el número óptimo de rezagos (p) que debe incluirse en un modelo de Vectores Autorregresivos ( VAR ) formado por las series entropia_global , entropia_conectados e inflacion_quincenal_deses. Esto es indispensale para ejecutar las pruebas de Causalidad de Granger sin que haya sobreajuste, autocorrelación residual.
